# سند الطالب | SANAD — وثيقة المشروع (المرحلة الثالثة)

مبادرة طلابية مستقلة لخدمة طلاب كلية الذكاء الاصطناعي في جامعة البلقاء التطبيقية.

---

## الجديد في المرحلة الثالثة: إطلاق أداة «رتّب دوامي»

تم تفعيل الأداة الثانية بالكامل بعد دمجها مع بنية بيانات المواد السابقة والمحرك التوافقي:

1. **مدخلات الشعب والحزم المتكاملة**:
   - إدخال شعب متعددة لكل مادة، بما في ذلك اللقاءات المتعددة (محاضرات + مختبر/عملي إلزامي).
   - حزمة اللقاءات كاملة لا يمكن تجزئتها أو إسقاط أي لقاء منها لتفادي التعارض.
   - دعم تثبيت شُعب محددة (Pinning) لإلزام المحرك باختيارها.
   - إمكانية تحديد نمط اللقاء (وجاهي أو عن بُعد).

2. **الفصل بين القيود الإلزامية والتفضيلات**:
   - **القيود الإلزامية**: منع التداخل، احترام أوقات الانتقال الوجاهية، حظر أوقات الالتزامات والعمل والاستراحات، التقيد بأبكر بداية وآخر نهاية، ومنع الحضور في الأيام المحظورة.
   - **التفضيلات**: تقليل أيام الحضور، تقليل إجمالي الفراغات بين المحاضرات، وتفضيل يوم إجازة معين.

3. **المحرك وتشخيص التعارضات**:
   - خوارزمية بحث واستكشاف مع استبعاد مبكر (Backtracking with Pruning) للحفاظ على خفة وسرعة التصفح.
   - حماية من الجمود التقني: التوضيح بأن البحث توقف بسبب حد تقني عند ضخامة الاحتمالات دون نفي وجود حل.
   - تقرير تشخيصي عند انعدام الحل يوضح بدقة الشُعب المتعارضة والفترات الممنوعة ويقترح ما يمكن تعديله دون تخفيف القيود تلقائياً.

4. **عرض النتائج والطباعة**:
   - عرض حتى 3 جداول صالحة للمفاضلة مرتبة حسب أفضلية التفضيلات.
   - جدول أسبوعي واضح للكمبيوتر، وبديل مقسم بالأيام للهواتف.
   - بيان عدد أيام الحضور، أوقات البداية والنهاية، وإجمالي الفراغات مع شرح طريقة الحساب.
   - حفظ الجدول محلياً، مع فحص مستمر ينبه الطالب عند تعديل الشعب بعد الحفظ بأن الجدول يحتاج إلى مراجعة.
   - تنسيق طباعة كامل مخصص (`@media print`) للحصول على نسخة ورقية أو PDF بدون عناصر التحكم.
   - إظهار التنبيه المعتمد: *«الجداول مبنية على مدخلاتك، ولا تعكس توفر المقاعد أو الاتصال بنظام تسجيل الجامعة»*.

## فحوصات التحقق وضمان الجودة المنجزة (QA Checklist)

- [x] **التعارض الكامل والجزئي**: تم التحقق من استبعاد أي شعبتين تتداخل أوقاتهما في نفس اليوم.
- [x] **اللقاءات المتلاصقة**: تم التأكد من السماح ببدء لقاء عند انتهاء السابق مباشرة عندما يكون وقت الانتقال 0 أو أحدهما عن بُعد.
- [x] **الشعب متعددة اللقاءات والمختبرات**: تم التحقق من التعامل مع لقاءات الشعبة كوحدة متكاملة دون إسقاط أي مختبر.
- [x] **الأوقات الممنوعة ووقت الانتقال**: تم التحقق من استبعاد أي تداخل مع فترات العمل أو وقت الانتقال المحدد.
- [x] **تثبيت شعبة**: تم التحقق من إلزام المحرك باختيار الشعبة المثبتة فقط.
- [x] **انعدام الحل**: تم التحقق من ظهور التقرير التشخيصي التفصيلي واقتراحات الحل العملية.
- [x] **الحفظ والطباعة**: تم اختبار حفظ الجدول واستعادته وظهور تحذير التعديل اللاحق، واختبار تنسيق الطباعة الورقية.
