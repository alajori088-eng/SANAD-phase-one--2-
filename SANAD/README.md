# سند الطالب | SANAD — وثيقة المشروع (المرحلة الثانية)

مبادرة مستقلة لخدمة طلاب كلية الذكاء الاصطناعي في جامعة البلقاء التطبيقية. صُممت المنصة لتوفير مساحة تقنية هادئة تمكّن الطالب من بناء دليله الدراسي ومتابعة تقدمه محلياً.

---

## الجديد في المرحلة الثانية: تفعيل «تخصصي وموادي»

تم إطلاق الأداة الأولى «تخصصي وموادي» مع بناء نظام تخزين وتحقق مشترك يخدم كافة الأدوات اللاحقة، ويتضمن:

1. **دليل المواد المخصص**:
   - إضافة وحفظ وتعديل وحذف المواد الدراسية.
   - حقول المادة: الاسم (إلزامي)، الرمز، الساعات المعتمدة، السنة الدراسية، الفصل الدراسي، التصنيف (متطلب جامعة، متطلب كلية، متطلب تخصص، اختياري، غير محدد).
   - إمكانية ربط المادة بأكثر من تخصص برمجيًا دون تكرار بنيتها.
   - تحديد «مواد هذا الفصل» وتحديد «المفضلة» والفرز والتصفية المباشرة.

2. **صفحة / عرض تفاصيل المادة**:
   - تنويه واضح بالمدخلات اليدوية غير الرسمية.
   - إضافة وإدارة الموضوعات الدراسية مع تتبع حالتها: (لم أبدأ، قيد الدراسة، مكتمل، بحاجة مراجعة).
   - إضافة المصادر والروابط المرتبطة بكل موضوع (شرح، ملخص، تدريب، مرجع، إلخ).
   - فحص الروابط حصراً بصيغتي `http://` و`https://`، مع توضيح أن النظام يحفظ روابط خارجية ولا يدعم رفع ملفات.

3. **البحث الشامل والمصنف**:
   - محرك بحث مباشر في الصفحة الرئيسية يفهرس المواد، الموضوعات، والمصادر.
   - تصنيف النتائج والانتقال المباشر للمادة أو الموضوع عند النقر.

4. **الأمان والتخزين المحلي**:
   - تخزين محلي على المتصفح عبر المفتاح `sanad_student_data_v2` برقم إصدار `schemaVersion: 2`.
   - كشف البيانات التالفة وحمايتها من المسح أو الاستبدال الصامت.
   - معالجة أخطاء سعة التخزين برسائل صريحة.
   - تطهير المخرجات لحماية المستخدم من هجمات XSS.
